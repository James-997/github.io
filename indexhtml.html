HTML

Definição de Termos

O que é TAG?

Tag são as divisões de um documento HTML, algumas específicas com funções especiais, outras abarcando o documento inteiro como a própria tag <HTML>

O que é classes?

Classe é uma característica que pode ser atribuída às tag que indica qual tag será modificada pelo CSS, uma mesma classe pode ser atribuída a várias tags, mantendo as mesmas características do CSS.

O que é id?

ID é inserido na tag para indicar ao CSS qual tag será modificada, ele só se refere a uma tag.

TAGS

Qual é o papel de um <div>

<div> é uma tag que divide o documento, nele são aplicados os ids ou classes, indicando que haverá um diferenciação.

O que faz a tag <ul>

A tag <ul> indica que haverá uma lista, sendo cada componente indicado por <li> e seus componentes não há nada que indique ordem.

Exemplo

  • Primeiro Item
  • Segundo Item
  • Terceiro Item
O que faz a TAG <ol>

É outra forma de listagem, tendo sua ordem indicada podendo ser por números e letras.

Como é feito é indicado por list-style-type no css.

Exemplo

  1. Primeiro Item
  2. Segundo Item
  3. Terceiro Item
O que faz a tag <table>?

A tag <table> indica que será feita uma tabela.

A tag <header> indica que será aberto o cabeçalho da tabela. A tag <tr> indica que será feito uma linha, e dentro da linhas as tags A tag <th> para uma coluna de cabeçalho. A tag <tbody> indica que o corpo da tabela será feito, onde a tag <td> indica cada coluna novamente dentro do A tag <tr>.
